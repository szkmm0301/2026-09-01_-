02 / LEARNING APPROACH

「強み」ではなく、
取り組み方を伝える。

01

分からない点を
整理する

「どこまで分かったか」「何を試したか」「どこで止まったか」を分けて考えます。質問するときにも状況を簡潔に説明できるよう心掛けます。

02

小さく動かし、
結果を確認する

一度に多くを変更せず、小さな単位でコードを実行します。期待した結果と実際の結果を比べ、エラーが出た場合は変更箇所を絞って確認します。

03

学んだことを
記録する

新しく知った用語、エラーの原因、解決までに試したことを記録します。次に同じ問題が起きたとき、記録を手掛かりに自分で対応できるようにします。

03 / CURRICULUM

職業訓練で学んだこと。

ヒートウェーブ「Java&Pythonシステム開発科」のカリキュラムを通じて、プログラミングだけでなく、Web、データベース、システム開発の流れを横断的に学びました。

JAVA

Javaプログラミング

変数、配列、制御文、クラスとオブジェクト、オブジェクト指向、例外処理を学習。API、GUI、JSP／Servletを使った演習にも取り組みました。Springの学習を進めています。

  • オブジェクト指向
  • クラス設計
  • 例外処理
  • JSP / Servlet
  • Spring（学習中）

PYTHON

Pythonプログラミング

変数とデータ型から、コレクション、条件分岐、関数、オブジェクト、モジュールまで、プログラムを組み立てる基礎を学びました。インベーダーゲームの開発を行っています。

  • データ型
  • コレクション
  • 関数
  • モジュール
  • ゲーム開発（実践中）

DATABASE

SQL・データベース

データの検索・追加・更新・削除、絞り込み、式と関数、集計、トランザクション、テーブル作成を演習しました。

  • CRUD
  • 集計
  • トランザクション
  • テーブル作成

WEB

Webプログラミング

HTMLによる文書構造、CSSによる装飾とレイアウト、JavaScriptの変数・演算子・条件分岐・基本メソッドを学びました。

  • HTML
  • CSS
  • JavaScript
  • レスポンシブ基礎

COMPUTER

コンピューター基礎

ハードウェアとソフトウェアの役割を学び、プログラムが動作する土台を理解しました。操作だけで終わらず、仕組みを意識して学習しています。

  • ハードウェア
  • ソフトウェア
  • 開発環境
  • IT基礎

DEVELOPMENT

システム開発工程

課題に沿って、要件定義、概要・詳細設計、製造、評価、結合テスト、プロジェクト管理、成果発表までの一連の流れを経験しました。

  • 要件定義
  • 設計
  • 製造
  • テスト

04 / PRACTICE

総合演習で、
開発の流れを実践。

  1. 01

    UNDERSTAND

    課題と要件を理解する

    何を作るのか、利用者にとって何が必要かを整理し、開発の目的を確認します。

  2. 02

    DESIGN

    概要・詳細を設計する

    処理の流れやデータの扱いを検討し、実装前に必要な仕様を具体化します。

  3. 03

    BUILD & TEST

    製造し、動作を確かめる

    設計をもとに実装し、評価・結合テストを通じて期待どおりに動作するか確認します。

  4. 04

    PRESENT

    成果を分かりやすく伝える

    制作物の目的、工夫、学んだことを整理し、成果物としてプレゼンテーションします。
